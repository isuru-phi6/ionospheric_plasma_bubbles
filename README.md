# ionospheric_plasma_bubbles
Interpretable machine learning of equatorial plasma bubbles over Sri Lanka (70–90°E) using ESA Swarm IBI data, 2014–present. Builds a pass-level dataset, maps occurrence climatology, trains XGBoost vs logistic and climatology baselines with a time-based split, explains drivers with SHAP, and tests storm-time bubble enhancement vs suppression.
